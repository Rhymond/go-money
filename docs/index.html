Why go-money?

Financial applications demand exactness. go-money gives you that — and a clean API to boot.

🔢

Integer arithmetic

Amounts are stored as int64 in the smallest currency unit (cents, pence, paise…), so rounding errors simply cannot occur.

🌍

150+ currencies

Full ISO 4217 coverage with correct symbols, decimal separators, and thousands separators out of the box.

⚖️

Penny-perfect allocation

Split and Allocate distribute amounts without ever losing a single cent.

📝

Words conversion

Convert any amount to human-readable English words for cheques, invoices, or legal documents.

🔄

JSON serialization

Built-in MarshalJSON / UnmarshalJSON for seamless REST API and database integration.

📦

Zero dependencies

Pure Go standard-library implementation. No transitive dependencies to audit or update.

🔒

Immutable values

Every operation returns a new Money instance. Safe to use concurrently without locks.

🧮

Percentage support

Calculate tax, discounts, and tips with Percentage(p) — results are always rounded correctly.

Quick Start

Install, import, and start writing financial logic in minutes.

Installation

# Requires Go 1.21+
go get github.com/im-adarsh/go-money

Basic arithmetic

import money "github.com/im-adarsh/go-money"

// Amounts are in the currency's smallest unit.
// 1000 cents = $10.00
price := money.New(1000, "USD")
tax   := price.Percentage(8.5)       // $0.85

total, _ := price.Add(tax)           // $10.85
fmt.Println(total.Display())         // "$10.85"

Penny-perfect splitting

bill := money.New(10085, "USD")   // $100.85
shares, _ := bill.Split(3)

for _, s := range shares {
    fmt.Println(s.Display())
}
// $33.62
// $33.62
// $33.61   ← leftover penny goes first

Ratio allocation

profit := money.New(10000, "USD")  // $100.00
parts, _ := profit.Allocate(60, 30, 10)

parts[0].Display()  // "$60.00"
parts[1].Display()  // "$30.00"
parts[2].Display()  // "$10.00"

JSON serialization

m := money.New(1234, "EUR")
b, _ := json.Marshal(m)
// {"amount":1234,"currency":"EUR"}

var r money.Money
json.Unmarshal(b, &r)
r.Display()  // "€12.34"

Money in words

money.New(15050, "USD").ToWords()
// "one hundred fifty dollar and fifty cents only"

money.New(100, "GBP").ToWords()
// "one pound only"

money.New(100, "JPY").ToWords()
// "one hundred yen only"

API Reference

Every method returns a new Money instance and leaves the receiver unchanged.

Construction

FunctionDescription
New(amount int64, code string) *MoneyCreate a new Money value. amount is in smallest currency unit; code is ISO 4217.

Accessors

MethodReturnsDescription
Amount() int64int64Raw value in smallest unit (e.g. cents).
Currency() *Currency*CurrencyCurrency metadata (Code, Fraction, Grapheme…).
AsParts() (int64, int64)whole, fracSplits amount into whole-unit and fractional-unit parts.
Display() stringstringHuman-readable formatted string (e.g. "$12.34").
ToWords() stringstringEnglish words (e.g. "twelve dollars and thirty-four cents only").

Comparisons (require same currency)

MethodDescription
Equals(om *Money) (bool, error)m == om
GreaterThan(om *Money) (bool, error)m > om
GreaterThanOrEqual(om *Money) (bool, error)m ≥ om
LessThan(om *Money) (bool, error)m < om
LessThanOrEqual(om *Money) (bool, error)m ≤ om
Compare(om *Money) (int, error)Returns −1, 0, or +1.
SameCurrency(om *Money) boolReports whether currencies match.

Assertions

MethodDescription
IsZero() boolAmount == 0
IsPositive() boolAmount > 0
IsNegative() boolAmount < 0

Arithmetic

MethodDescription
Add(om *Money) (*Money, error)m + om. Requires same currency.
Subtract(om *Money) (*Money, error)m − om. Requires same currency.
Multiply(mul int64) *Moneym × mul.
Divide(div int64) *Moneym ÷ div (integer division — may lose pennies).
Percentage(p float64) *Moneyp% of m, rounded to nearest smallest unit.
Absolute() *Money|m|
Negative() *Money−|m|
Round() *MoneyRound to nearest whole currency unit.

Allocation (lossless)

MethodDescription
Split(n int) ([]*Money, error)Divide into n equal parts; leftover distributed round-robin.
Allocate(rs ...int) ([]*Money, error)Distribute by ratio; leftover distributed round-robin.

Serialization

MethodDescription
MarshalJSON() ([]byte, error)Encodes as {"amount":N,"currency":"XYZ"}.
UnmarshalJSON([]byte) errorDecodes from {"amount":N,"currency":"XYZ"}.

Currency management

FunctionDescription

AddCurrency(code, grapheme, template, decimal, thousand string, fraction int) *CurrencyRegister or override a currency.
AddCurrencyMeta(code, mainWord, subWord string)Register English word names for ToWords().
